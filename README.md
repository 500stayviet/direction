# 현장동선 — 부동산 현장 고객 & 동선 맞춤 매물 관리

토스 스타일 UI의 모바일 웹앱. 중개인이 고객 등록, 방문 일정 구성, 현장 브리핑·네비 연동을 한 흐름으로 처리합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 엽니다.  
스마트폰에서 전화/네비 원클릭을 쓰려면 같은 Wi-Fi의 기기 IP로 접속하거나 배포 URL을 사용하세요.

## 핵심 기능

- **원클릭 전화** (`tel:`) — 고객·협력 부동산 번호
- **원클릭 네비** — 카카오내비 / Tmap / 네이버 지도 선택, LocalStorage 기억
- **고객 / 일정 / 매물 수정** — 상세 화면 우측 상단 [수정]
- **가변형 매물 루트** — 추가·삭제, 구간 이동거리·시간 요약, 스마트 루트 알림
- **현장 리드 모드** — 1번 → 2번 → 3번 버튼 스텝 네비

데이터는 브라우저 LocalStorage에 저장됩니다.
