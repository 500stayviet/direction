> **대상:** 강동구 등 **지역 부동산 공인중개사사무소** 직원

## 2. 핵심 카피 (그대로 써도 됨)

### 2.1 메인 슬로건 (택1)

1. **현장 고객부터 동선까지, 한곳에서** ← 앱 공식 카피  
2. **임장 날, 전화·네비·매물 정보를 한 손에**  
3. **카톡·메모 대신, 우리 업장 전용 현장 노트**  
4. **고객 10명·매물 10건, 매달 쌓여도 정리는 한곳**

### 2.2 서브 카피

- 부동산 중개 **현장**을 위한 **모바일 웹** — 설치 없이 바로 사용  
- **고객 · 매물 · 방문 일정(네비)** 를 계정 하나로  
- **티맵 · 카카오 · 네이버** 원클릭 길안내  
- **조건에 맞는 매물·고객** 자동 후보  
- **팀 공유:** 코드로 합류 후, **공유할 항목만** 선택  
- **무료** 이용 (서비스 유지를 위해 일부 화면에 광고가 있을 수 있음)

### 2.3 CTA (행동 유도)

- **지금 무료로 시작하기**  
- **QR 스캔 → 회원가입 (1분)**  
- **약관·개인정보: ○○○/terms**

### 2.4 신뢰·주의 한 줄 (작은 글씨)

- 공인중개 **업무 편의 도구**이며, 계약·실거래를 대행하지 않습니다.  
- 입력 정보·외부 전달은 **이용자 책임**입니다.  
- 팀 공유 데이터는 **업장 업무**로 남을 수 있습니다.

## 3. 캡처해야 할 화면 (체크리스트)

스마트폰 **375×812** 또는 실제 기기에서 캡처 후, 전단에는 **기기 프레임(mockup)** 을 씌우면 전문적으로 보입니다.

| # | URL | 캡처 포인트 | 전단에서의 역할 |
|---|-----|-------------|-----------------|
| 1 | `/` (로그인 후) | 4개 빠른 메뉴(고객·매물·일정·네비), 업장명 | **메인 히어로** |
| 2 | `/customers` | 카드 2~3개, 색 칩·스와이프 힌트 | 「고객 정리」 |
| 3 | `/properties/[id]` | 주소·금액·현장 정보 | 「매물 브리핑」 |
| 4 | `/navi` | 일정 목록 + 「시작」 | 「네비 시작」 |
| 5 | `/navi/[scheduleId]` | 1번·2번 매물 버튼 (현장 리드) | **차별점** — 임장 당일 |
| 6 | `/customers/[id]` | 「조건에 맞는 매물」 섹션 | 매칭 기능 |
| 7 | `/account` | 팀 공유 코드 영역 | 팀 기능 (뒷면) |
| 8 | `/signup` | 간단한 가입 폼 | 「1분 가입」 |
| 9 | `/about#guide` | 사용설명 일부 | 뒷면 「How to」 |

### 캡처 팁

- **데모 계정**으로 로그인해 **실제 같은 한글 데이터** (강동구 주소, 전세/월세 등)  
- 개인 **실전화번호·실주소**는 가리거나 가짜 데이터 사용  
- **상태바·URL바**는 크롬 DevTools 모바일 모드 또는 PWA 전체화면  
- 네비 현장 화면은 **광고 없음** — 「현장에 집중」 강조용으로 좋음

## 4. 「3단계 사용법」 뒷면용

```
① 회원가입 (아이디 · 업장명 · 약관 동의)
        ↓
② 고객·매물 등록 (메시지·마이크·사진으로 칸 채운 뒤 **등록하기**)
        ↓
③ 방문 일정 만들기 → 네비에서 원클릭 전화·길안내
```

**팀 쓰는 업장:**  
「내 정보 → 공유 코드 → 동료 입력 → 리스트에서 **팀 공유하기** ON」

## 5. 타깃별 메시지 (강동구 부동산 예시)

### 5.1 사장·대표에게

> 직원마다 흩어진 고객·매물 메모를 **한 시스템**으로.  
> **필요한 것만** 팀 공유 — 전체 노출 아님.

### 5.2 현장 직원에게

> 임장 날 **전화 → 네비 → 다음 매물** 버튼만 누르세요.  
> 호실·비밀번호·관리비 **한 화면**.

### 5.3 IT 잘 모르는 분에게

> **앱 설치 없음.** 카카오톡처럼 **링크·QR**만 열면 됩니다.  
> 홈 화면에 **추가**하면 앱처럼 씁니다.

## 6. QR·URL

1. 배포 URL 확인 (`NEXT_PUBLIC_APP_URL` 또는 Vercel 도메인)  
2. QR 생성: `https://your-domain/signup` 또는 `https://your-domain/`  
3. 전단 하단: **「QR 스캔 → 회원가입」** + 짧은 URL 텍스트
