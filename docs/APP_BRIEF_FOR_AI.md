# 현장동선 — 서비스·기술·운영 설명서 (AI·법률·검토용)

> **용도:** 다른 AI·변호사·검토자에게 붙여넣어 질문할 때 쓰는 내부 문서  
> **작성 기준일:** 2026년 8월 12일  
> **비공개:** 외부 배포·공유 시 민감 정보(운영 이메일, URL, 키)는 직접 가리고 사용

---

## 1. 한 줄 요약

**현장동선**은 대한민국 **부동산 중개 현장**을 위한 **모바일 웹 앱(PWA 성격)** 입니다.  
중개인·보조·현장 스태프가 **고객·매물·방문 일정(네비)** 을 스마트폰에서 기록하고, **원클릭 전화·길안내**, **조건 매칭**, **동료 팀 공유**까지 한곳에서 처리하도록 만든 **선택적 업무 편의 도구**입니다.  
공인중개법상 필수 시스템이 아니며, 이용자가 자발적으로 가입·이용합니다.

---

## 2. 서비스 취지·설계 의도

### 2.1 왜 만들었는가

- 현장에서 **전화번호·주소·호실·비밀번호·동선**을 메모·카톡·엑셀에 흩어 두는 비효율을 줄이기 위함
- **임장(방문) 당일** 「전화 → 네비 → 다음 매물」 흐름을 **한 화면(네비/현장 리드)** 에 모으기 위함
- 같은 **공인중개사무소(업장)** 동료끼리 **필요한 항목만** 선택적으로 공유 (전체 자동 공개 아님)
- **허위 매물·허위 고객** 등 악용에 대비한 **계정 정지·소프트 삭제·운영자 복원** 체계

### 2.2 무엇이 아닌가

- 부동산 **중개·계약·실거래 신고**를 대행·보증하는 플랫폼 **아님**
- **매물 DB·포털** (네이버 부동산 등) **아님**
- **주민등록번호·고유식별정보**를 수집하지 **않음** (약관·UI 설계 기준)
- **사이트 전체 회원 간 자동 매칭(현장동선내 공유)** 은 UI에 「준비 중」으로 표시, **아직 미완**

### 2.3 타깃 사용자

- 강동구 등 **지역 부동산 공인중개사사무소** 직원
- 고객 응대·임장을 자주 하는 **중개 보조·현장 스태프**
- **1업장 월 고객 10명·매물 10건** 수준의 소규모 사용을 전제로 한 설계

## 4. 화면·기능 목록 (이용자 앱)

### 4.1 하단 탭 (4개)

| 탭 | 경로 | 설명 |
|----|------|------|
| 홈 | `/` | 빠른 등록(고객·매물·일정·네비), 업장명·인사, 계약 마감 알림 |
| 고객리스트 | `/customers` | 고객 목록·검색·스와이프 삭제/계약완료 |
| 매물리스트 | `/properties` | 매물 목록·유형/거래/보증금 칩·팀 공유 |
| 네비 | `/navi` | 방문 일정 선택 → 현장 리드 모드 진입 |

### 4.2 주요 하위 화면

| 경로 | 기능 |
|------|------|
| `/signup`, `/login` | 아이디 중복 확인, 약관 동의, 업장명 자동 보정 |
| `/customers/new`, `/customers/[id]` | 고객 등록·수정, 조건에 맞는 매물, 팀 공유 토글 |
| `/properties/new`, `/properties/[id]` | 매물 등록·수정, 현장 비밀번호·협력 부동산, 조건 매칭 |
| `/schedules/new`, `/schedules/[id]` | 방문 일정·매물 슬롯·도착 시간·동선 순서 |
| `/navi/[scheduleId]` | **현장 리드** — N번 매물 순차 전화·네비 (하단 탭 숨김, 광고 없음 원칙) |
| `/account`, `/account/edit` | 내 정보, 팀 공유 코드 생성/참여, 탈퇴 |
| `/about` | 서비스 소개·사용설명 |
| `/terms` | 이용약관·개인정보·광고·면책 |

### 4.3 핵심 UX·동작

- **스와이프:** 리스트에서 오른쪽=삭제, 왼쪽=계약완료(고객·매물) / 종료(네비)
- **팀 공유 3단계:** ① 개인 계정 → ② 공유 코드로 **공간** 합류 → ③ 항목별 「팀 공유하기」 ON 시에만 팀원에게 표시
- **공유 코드:** 약 5분 유효 (짧은 TTL)
- **조건 매칭:** 같은 계정(또는 팀) 내 고객↔매물 조건 비교 (유형·금액·입주·주차 등)
- **중복 경고:** 동일 전화(고객)·동일 주소+호실(매물) 재등록 시 안내
- **데모 데이터:** 최초 가입 시 체험용 데이터 (팀 공유 공간과 분리)
- **계정 정지:** 로그인은 가능, **홈 외 기능 차단** + 사유 표시 (`AccountSuspendedGate`)
- **Realtime:** 앱 화면이 켜져 있을 때 팀 공유 변경 실시간 반영 (푸시 알림 아님)

## 5. 관리자 패널 (`/admin`)

### 5.1 접근

- 별도 **관리자 계정** (`admin_users` 테이블), 앱 회원과 분리
- Bearer 토큰 세션 (12시간), 로그인 5회 실패 시 30분 잠금
- 비활성화된 직원은 **다음 API 호출부터 즉시 401**

### 5.2 탭·기능

| 탭 | 기능 |
|----|------|
| 가입자 | 최근 가입 20명 + 더 보기, 계정 상세·고객/매물/네비 열람 |
| 검색 | 아이디·상호·이름·전화로 가입자 검색 |
| 팀 | 업장 공유 공간·멤버, 강퇴(슈퍼·직원) |
| 삭제 | 소프트 삭제 3건 + 검색, 탈퇴 계정 3건 + 검색, 슈퍼만 복원 |
| 직원 (슈퍼) | 관리자 목록·비활성/활성, 슈퍼/직원 생성 |
| 로그 (슈퍼) | 감사 로그 (로그인·정지·복원·PII 열람 등) |

### 5.3 권한 (슈퍼 vs 직원)

| 행동 | 슈퍼 | 직원 |
|------|------|------|
| 가입자·팀·삭제 목록 조회 | ✓ | ✓ |
| 고객/매물 전화·호실 (마스킹) | ✓ (해제+감사) | ✗ |
| 계정 정지/해제 | ✓ | ✓ |
| 소프트삭제·탈퇴 복원 | ✓ | ✗ |
| 팀원 강퇴 | ✓ | ✓ |
| 직원 CRUD·로그 | ✓ | ✗ |

## 6. 수집·저장 데이터

### 6.1 회원(프로필)

- 아이디, 비밀번호(해시), 비밀번호 힌트, 이름, 전화, 업장명(상호)
- 정지 여부·사유·시각, `last_seen_at` (오늘 접속 집계)
- **주민등록번호 수집 안 함**

### 6.2 업무 데이터 (JSON payload)

- **고객:** 이름, 전화, 희망 조건(유형·금액·입주·주차·애완 등)
- **매물:** 주소, 호실, 보증금/월세, 관리비, 현장 비밀번호, 협력 부동산 등
- **네비(일정):** 방문 매물 순서, 도착 시간, 고객 연결

### 6.3 팀·운영

- `workspaces`, `workspace_members` — 공유 공간·역할
- `deleted_accounts` — 탈퇴 아이디 재가입 차단
- `audit_logs` — 관리자·팀 조치 기록
- `admin_users`, `admin_login_attempts` — 관리자 인증·잠금
- `profiles.ui_prefs` — 팀 알림 읽음·목록 숨김 등

### 6.4 삭제 정책

- 목록 삭제 = **소프트 삭제** (`deleted_at`), 운영자 복원 가능
- 탈퇴 = 로그인 불가 + 아이디 재사용 불가, **팀 공유 데이터는 자동 파기 안 함** (약관 명시)
- 팀원이 타인 공유 항목 「삭제」= **본인 화면 숨김** (원본 유지)

## 7. 인증·보안 (코드 의도)

| 항목 | 구현 |
|------|------|
| 앱 로그인 | Supabase Auth + 서버 API (`/api/auth/login`), httpOnly 쿠키 |
| 관리자 | HMAC 서명 토큰, DB에서 매 요청 `active`·`role` 재검증 |
| PII | 관리자 UI에서 전화·호실 마스킹, 슈퍼 해제 시 감사 로그 |
| Rate limit | 관리자 로그인 5회/15분 → 30분 잠금 |
| RLS | Supabase Row Level Security — 본인·팀 공간만 접근 |
| Realtime | 본인 `user_id` + 소속 `workspace_id` 구독만 |

## 9. 약관·법무 관련 요지 ( `/terms` )

> 아래는 **약관에 적힌 내용 요약**이며 법률 자문이 **아닙니다**.  
> 다른 AI·변호사에게 「이 문서 + 약관 전문」을 함께 주세요.

### 9.1 이용약관 핵심

1. **업무 편의 도구**, 의무 서비스 아님  
2. **탈퇴 아이디 재사용 불가**  
3. **팀 공유:** 코드 합류 → 항목별 opt-in 공유, 지역명 자동 공유 아님  
4. **탈퇴 ≠ 공유 데이터 즉시 삭제**, 업장 업무 자산으로 보관 가능  
5. **계정 정지:** 로그인 가능·홈 외 제한, 허위 등록 시 정지 가능  
6. **운영자** 소프트삭제 복원·탈퇴 복구·팀원 처리 가능  
7. **금지:** 허위 매물/고객, 비방, 크롤링, 역공학 등  
8. **면책:** 매칭 정확성·계약 결과 보증 없음, 이용자 책임

### 9.2 개인정보 핵심

- 수집: 이름·전화·주소(구·동 등)·호실(선택), 업무 기록, 팀·UI 설정, 정지·감사 로그  
- **운영자(슈퍼/직원) 접근** — 조회·조치·감사 기록 (§5)  
- **판매하지 않음** (약관 표현)  
- 이용자·기기·팀 코드 관리 책임은 **이용자**  
- 문의: 약관·소개에 **운영 이메일** 기재 (`bek94900@gmail.com`)

### 9.3 AI·변호사에게 자주 물을 질문 예시

1. 부동산 중개 **업무 도구**로서 개인정보보호법·공인중개법상 **추가 의무** (사업자 신고, 처리방침 게시 위치 등)  
2. **팀 공유 데이터**가 탈퇴 후에도 남는 구조의 **적법성·보관 기간**  
3. **전화·주소·호실** 처리가 **민감정보/개인정보** 해당 여부와 **마스킹·감사로그** 적절성  
4. **AdSense** + **무료 서비스** + **향후 유료** 전환 시 **약관·광고 표시** 요건  
5. **Vercel Hobby(비상업)** 로 **영업 중개사무소에 제공** 시 **플랫폼 약관 리스크**  
6. **운영자 패널** 접근·PII 열람 기록이 **내부통제·개인정보** 측면에서 충분한지  
7. **허위 매물 정지** 조치의 **약관 근거·이의 절차** 명시 수준  
8. **미성년·대리 중개** 등 이용자 자격 제한 필요 여부

## 13. 붙여넣기용 메타 (질문 시작 템플릿)
