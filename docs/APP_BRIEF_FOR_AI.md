## 1. 한 줄 요약

**현장동선**은 대한민국 **부동산 중개 현장**을 위한 **모바일 웹 앱(PWA)** 입니다.  
중개인·보조·현장 스태프가 **고객·매물·방문 일정(네비)** 을 스마트폰에서 기록하고, **원클릭 전화·길안내**, **조건 매칭**, **동료 팀 공유**까지 한곳에서 처리하는 **선택적 업무 편의 도구**입니다.  
공인중개법상 필수 시스템이 아니며, 이용자가 자발적으로 가입·이용합니다.

**운영 주체(사업자):** 상호 옆나라 · 대표 백경엽 · 사업자등록번호 664-21-02146  
**서비스명:** 현장동선 (`SITE` 상수·푸터·약관 동일 출처)

## 2. 서비스 취지·설계 의도

### 2.1 왜 만들었는가

- 현장에서 **전화번호·주소·호실·비밀번호·동선**을 메모·카톡·엑셀에 흩어 두는 비효율을 줄이기 위함
- **임장(방문) 당일** 「전화 → 네비 → 다음 매물」 흐름을 **한 화면(네비/현장 리드)** 에 모으기 위함
- 같은 **공인중개사사무소(업장)** 동료끼리 **필요한 항목만** 선택적으로 공유 (전체 자동 공개 아님)
- **허위 매물·허위 고객** 등 악용에 대비한 **계정 정지·소프트 삭제·운영자 복원** 체계

### 2.2 무엇이 아닌가

- 부동산 **중개·계약·실거래 신고**를 대행·보증하는 플랫폼 **아님**
- **매물 DB·포털** (네이버 부동산 등) **아님**
- **주민등록번호·고유식별정보**를 수집하지 **않음**
- **사이트내 매칭(업장 내):** 같은 `workspace`의 고객·매물끼리 조건 매칭. **팀원 비공유 항목도 매칭 풀에 포함**(리스트 표시는 비공유 유지). ① 내 리스트 매칭은 나중 등록 쪽에만 알람, ② 사이트내는 소유 쪽에만 알람.
- **알림·웹 푸시:** 뱃지·탭 제목·배너·파비콘·브라우저 Notification·Web Push(VAPID, `024_push_subscriptions`, cron `/api/cron/alerts`). 매칭은 미리보기 열람 시, 팀공유는 리스트 카드 탭 시 해제.

### 2.3 타깃 사용자

- 강동구 등 **지역 부동산 공인중개사사무소** 직원
- 고객 응대·임장을 자주 하는 **중개 보조·현장 스태프**
- **1업장 월 고객·매물 소수** 수준의 소규모 사용을 전제로 한 모바일(최대 폭 약 430px) UI

### 4.4 핵심 UX·동작

| 주제 | 동작 |
|------|------|
| **스와이프** | 오른쪽=삭제, 왼쪽=계약완료(고객·매물) / 종료(네비) |
| **팀 공유 3단계** | ① 계정 → ② 공유 코드로 **공간** 합류 → ③ 항목별 「팀 공유하기」 ON 시에만 팀원에게 표시 |
| **공유 코드** | 약 5분 TTL |
| **조건 매칭** | 동일 계정(또는 팀) 내 고객↔매물 (유형·금액·입주·대출·보증보험·주차·엘리베이터·애완 등) |
| **선호위치** | 고객: `preferredGus` / `preferredDongs`(`구\|동`). UI 기본 구 표시 강동구, 구+동 확정 후 하단 반영. 「전체」동 선택 가능. 리스트·상세 표시 |
| **업장명** | 「부동산」「공인중개사사무소」 없으면 저장 시 **「공인중개사사무소」** 자동 부여. 홈에서 이름 위 **작게** 표시(기본값「현장동선」은 숨김) |
| **계약 마감 안내** | 희망입주·임대희망 **시작일 기준 45일 전~30일 전** 매일 표시 (`CONTRACT_DEADLINE_DAYS=45`, `UNTIL=30`) |
| **원터치 네비 주소** | `toNaviAddress` → 시 이름 **서울특별시**. 목록 카드는 `formatCardAddress`로 「서울」 제거 |
| **빠른 입력** | 메시지·마이크·사진 → 「반영하기」는 폼만 채움. **고객등록하기/매물등록하기**가 저장. 마이크는 AI 없음. 메시지·사진 leftover만 DeepSeek |
| **매물 등록 기본값** | 대출·전세보증보험·주차 = **무** (`createEmptyProperty`) |
| **데모 시드** | 가입 직후 체험 고객·매물·일정. id `demo_*`. **팀 `workspace_id` 미연결**, 타 계정 접근 불가. **팀공유 아님** — 매칭 알람 체험만. TTL 약 7일 |
| **알람 뱃지** | 팀 공유·① 매칭(한쪽)·② 사이트내(소유 쪽)·기한. 브라우저 알림·Web Push 연동 |
| **계정 정지** | 로그인 가능, **홈 외 차단** + 사유 (`AccountSuspendedGate`) |
| **세션 무효/계정 종료** | 토큰 폐기·탈퇴 등으로 세션이 비면 상단(로그인/가입)·하단(알람 없음) **동기화** (`subscribeAuthChange`) |
| **Realtime** | 화면이 켜져 있을 때 팀 공유 변경 반영 |
| **Web Push cron** | GitHub Actions `cron-alerts.yml` — 매칭·**팀공유** (`kind=share`) |
| **등록 뒤로** | 고객·매물 신규: `router.back()` + 리스트 폴백 |

## 6. 수집·저장 데이터

### 6.1 회원(프로필)

- 아이디, 비밀번호(해시), 비밀번호 힌트, 이름, 전화, 업장명
- 정지 메타, `last_seen_at`, 요금/프로모 필드(`plan_tier`, `promo_source`, `matching_enabled`)
- `ui_prefs` — 팀 알림 읽음·목록 숨김 등
- **주민등록번호 수집 안 함**

### 6.2 업무 데이터 (JSON payload)

- **고객:** 이름·전화·거래유형·금액·입주·**선호위치(구·동)**·대출·보증보험·주차·애완·엘리베이터·메모 등
- **매물:** 주소·호실·비밀번호·금액·관리비·옵션·협력부동산·대출/보증보험/주차·건물·토지 필드 등
- **네비(일정):** 방문 매물 순서·도착 시간·고객 연결·팀공유

### 6.3 팀·운영 테이블 (요지)

- `workspaces`, `workspace_members`
- `customers`, `listed_properties`, `schedules` (+ `workspace_shared`, Realtime)
- `deleted_accounts`, `audit_logs`, `admin_users`, `admin_login_attempts`
- 프로모: `018` 계열
- `app_error_logs`: API 오류 수집(`withApiErrorLog`)

### 6.4 삭제 정책

- 목록 삭제 = **소프트 삭제** (`deleted_at`), 운영자 복원 가능
- 탈퇴 = 로그인 불가 + 아이디 재사용 불가, **팀 공유 데이터는 자동 파기 안 함** (약관)
- 팀원이 타인 공유 「삭제」= **본인 화면 숨김** (원본 유지)
- 데모 `demo_*` = 팀 공유·타계정 접근에서 **제외**

## 7. 인증·세션·보안 (코드 의도)

| 항목 | 구현 |
|------|------|
| 앱 로그인 | Supabase Auth + `/api/auth/*`, 앱 백업 `realty_app_auth_v1` + 쿠키(화면용, 힌트 제외) |
| 세션 UI 동기화 | `subscribeAuthChange` / `getAuthEpoch` — 홈·하단바·알람이 **같은 로그인 상태**를 봄 |
| 세션 정리 | `clearAuthRuntimeCache` — 캐시·엔티티·알람 유저 컨텍스트까지 비움 |
| 정지 | `refreshSuspendedFromServer` + `AccountSuspendedGate` |
| 탈퇴·삭제 계정 | account-status `deleted` 시 로컬 세션 정리 |
| 관리자 | HMAC 세션, 매 요청 active/role 재검증 |
| PII | 관리자 마스킹, 슈퍼 해제 시 감사 |
| RLS | 본인·팀 공간 |
| Realtime | 본인 `user_id` + 소속 `workspace_id` |
| 에러 로그 | 서버 API `withApiErrorLog` → `app_error_logs` |

## 8. 수익·비용 모델

- **현재:** 무료 + **AdSense** 준비 (홈·소개 등)
- **프로모/추천:** 가입 이벤트·프로모 코드(관리자 발급, UI 이벤트 섹션은 잠금 가능)
- **향후:** 유료 요금제·부가 기능 (약관 예고)
- **인프라:** Vercel + Supabase

## 9. 약관·법무 요지 (`/terms`)

> 약관 요약이며 **법률 자문이 아닙니다**.

1. 업무 편의 도구, 의무 서비스 아님  
2. 탈퇴 아이디 재사용 불가  
3. 팀 공유: 코드 합류 → 항목별 opt-in  
4. 탈퇴 ≠ 공유 데이터 즉시 삭제  
5. 계정 정지: 홈 외 제한  
6. 업장명 자동 「공인중개사사무소」 보정 가능  
7. 금지: 허위 매물/고객, 비방, 크롤링 등  
8. 면책: 매칭·계약 결과 보증 없음  
9. 문의: 운영 이메일(푸터·약관과 동일)  
10. 메시지·마이크·사진: 「반영하기」≠저장. 마이크는 DeepSeek 미사용. 메시지·사진 leftover·샘플(전화 마스킹) 가능

### AI·변호사에게 자주 물을 질문 예시

1. 중개 **업무 도구**로서 개인정보·공인중개법상 추가 의무  
2. 탈퇴 후 **팀 데이터 잔존** 구조의 적법성·보관 기간  
3. 전화·주소·호실·선호위치 처리와 마스킹·감사로그  
4. AdSense + 무료 + 향후 유료 시 표시·약관  
5. 관리자 PWA·패널 PII 통제  
6. 허위 매물 정지의 약관·이의 절차  
7. 데모 데이터·알람 UX와 개인정보 범위  
8. 메시지·사진 leftover AI(DeepSeek)와 브라우저 음성인식의 국외 이전·위탁
